# Simple RHCSA Tool

This is a simple Python project for RHCSA automation. It uses the `tkinter` library to create a window with buttons. When you click a button, it runs the Linux command.

## How it works

1.  **Libraries**: Only standard libraries (`tkinter`, `simpledialog`, `messagebox`).
2.  **Tabs**: Separates tasks into "User Management", "File Operations", and "System Info".
3.  **Output**: Shows exactly which Linux command is executed in the text box at the bottom.

## How to Run

1.  Make sure Python is installed.
2.  Run the code:
    ```bash
    python rhcsa_assistant.py
    ```
